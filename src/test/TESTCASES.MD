
# _Login Page_ 
## TC-1
### Название: Попытка авторизации с валидными данными 

**Предусловия:**
- Пользователь зарегистрирован в системе.
- Пользователь авторизован.

### Шаги воспроизведения

| № | Шаги |
|:---:|---|
| 1 | Перейти на страницу [Moysklad](https://online.moysklad.ru) |
| 2 | Ввести в поле (Логин) валидные данные "true@Login" |
| 3 | Ввести в поле (Пароль) валидные данные "truePassword" |
| 4 | Нажать на кнопку [Войти]|

### Ожидаемый результат: _наблюдаем главную страницу сайта_
